🌿 Sehatti — Asset Download Center

Download all images and assets used in the Sehatti website for self-hosting

📋 How to use this page:
Right-click each image below → "Save image as" → save to the path shown under each asset.
Then update index.html to use local paths instead of the Genspark CDN URLs.
After Downloading — Update index.html
1
Create an images/ folder next to your index.html
2
Save each image to the path shown on its card below
3
In index.html, do Find & Replace:
Replace https://www.genspark.ai/api/files/s/FFuc4nh6 → images/logo.png (etc. for each file)
4
Test locally by opening index.html in your browser
