🚀 Hosting Guide — 5 Options

⚡ Netlify (Recommended)

  1. Go to netlify.com
  2. Sign up / Log in (free)
  3. Drag & drop your project folder onto the deploy zone
  4. Site is live instantly at *.netlify.app
  5. Add custom domain in Site Settings

▲ Vercel

  1. Go to vercel.com
  2. Click "Add New → Project"
  3. Upload folder or connect GitHub repo
  4. Framework: Other (static)
  5. Deploy — live at *.vercel.app

🐙 GitHub Pages

  1. Create a GitHub repo
  2. Upload all project files
  3. Go to Settings → Pages
  4. Source: main branch, /root
  5. Live at username.github.io/repo

🌐 cPanel / Shared Hosting

  1. Login to cPanel
  2. Open File Manager
  3. Navigate to public_html/
  4. Upload all files (keep folder structure)
  5. Visit your domain — done

☁️ AWS S3

  1. Create S3 bucket (same name as domain)
  2. Enable "Static website hosting"
  3. Set index.html as index document
  4. Make bucket public (bucket policy)
  5. Upload all files via AWS Console
  6. Optional: add CloudFront CDN
Required versions: None — this is a plain HTML file. Any web server that can serve static files works. No Node.js, no PHP, no Python, no database.
SSL/HTTPS: Netlify & Vercel give free SSL automatically. cPanel: use Let's Encrypt from cPanel > SSL/TLS. AWS: use CloudFront + ACM certificate.

📦 Build & Download Your ZIP

How it works: Click the button below. Your browser will:
1. Fetch index.html + all guide files from this project
2. Try to fetch each image (some may be blocked by CORS — those get skipped with a note)
3. Package everything into a sehatti-project.zip and download it automatically

Note on images: Genspark CDN images use HTTP 302 redirects which some browsers block. If any image fails, use the Manual Download section below — then add them to the ZIP manually.

🖼️ Manual Image Download

If the auto-ZIP fails for any image, right-click each thumbnail → "Save image as…" and save it to the path shown.

After saving images manually: Open index.html in VS Code (or Notepad++), use Find & Replace (Ctrl+H) with the entries in assets/LOCAL_PATHS_PATCH.md to switch all CDN URLs to local paths.
